## 3. จัดการพนักงาน

เมนู **Employees** (ต้องการสิทธิ์ HR หรือ ADMIN)

### 3.1 ดูรายชื่อพนักงาน

- แสดงรายชื่อทั้งหมด พร้อมรหัสพนักงาน แผนก และจำนวนใบหน้าที่บันทึก
- กรองได้ด้วย: ค้นหาชื่อ, แผนก, สถานะ (Active/Inactive)

### 3.2 เพิ่มพนักงานใหม่

1. กดปุ่ม **"+ Add Employee"**
2. กรอกข้อมูล:

| ช่อง | ตัวอย่าง | หมายเหตุ |
|------|---------|---------|
| Employee Code | `EMP001` | ห้ามซ้ำ — ใช้รหัสพนักงานของบริษัท |
| Full Name | `สมชาย ใจดี` | ชื่อ-นามสกุล |
| Department | `วิศวกรรม` | เลือกจาก dropdown |
| Shift | `เช้า 08:00–17:00` | เวลาทำงาน |

3. กด **"Save"**

### 3.3 แก้ไขข้อมูลพนักงาน

1. คลิกชื่อพนักงาน → กด **"Edit"**
2. แก้ไขข้อมูลที่ต้องการ
3. กด **"Save"**

### 3.4 ปิดการใช้งานพนักงาน (ลาออก/หยุดงาน)

1. คลิกชื่อพนักงาน → กด **"Deactivate"**
2. ยืนยัน → พนักงานจะไม่สามารถแสกนเข้างานได้

> พนักงานที่ Deactivate จะ**ไม่ถูกลบ**จากระบบ — ข้อมูลการเข้างานยังอยู่ครบ

## 4. บันทึกใบหน้า (Enrollment)

ก่อนพนักงานจะแสกนได้ ต้องบันทึกใบหน้าก่อน **(ต้องการ 6 รูป)**

### 4.1 ขั้นตอนการ Enroll

1. เปิดหน้า **Employees** → คลิกชื่อพนักงาน
2. กด **"Enroll Face"**
3. ระบบจะเปิดกล้อง — ยืนตรงหน้ากล้อง
4. ถ่ายรูป **6 มุม** ตามที่ระบบแนะนำ:

```
   หันหน้า    หันซ้าย   หันขวา
     [📷]      [📷]      [📷]

   เงยหน้า   ก้มหน้า  หันซ้ายมาก
     [📷]      [📷]      [📷]
```

5. รูปผ่านการตรวจสอบ → แถบแสดง 6/6 ✅

### 4.2 เงื่อนไขรูปที่ดี

| ✅ ถูกต้อง | ❌ ไม่ผ่าน |
|-----------|----------|
| แสงสว่างพอ | แสงน้อย/ทวนแสง |
| มองเห็นหน้าชัดเจน | ใส่หน้ากากปิดบังใบหน้า |
| อยู่ใน frame | ออกนอกกรอบ |
| ภาพนิ่ง | ภาพเบลอ |

### 4.3 ลบ Template

ถ้าต้องการ Enroll ใหม่ (เช่น ใบหน้าเปลี่ยนไป):
1. หน้าพนักงาน → กด **"Delete All Templates"**
2. Enroll ใหม่จาก 0

## 5. ตรวจสอบการเข้างาน

เมนู **Attendance**

### 5.1 รายงานประจำวัน (Daily Status)

แสดงสถานะพนักงานทุกคนวันนี้:

| สถานะ | ความหมาย | สีแสดง |
|-------|---------|--------|
| **PRESENT** | มาทำงานตรงเวลา | 🟢 เขียว |
| **LATE** | มาแต่สาย | 🟡 เหลือง |
| **ABSENT** | ยังไม่มา | 🔴 แดง |

**กรองข้อมูล:**
- เลือกวันที่
- เลือกแผนก
- ค้นหาชื่อ

### 5.2 ประวัติการเข้างาน (Attendance Log)

แสดง log การแสกนทุกครั้ง พร้อม:
- เวลาที่แสกน
- ชื่อพนักงาน
- % ความแม่นยำ (Confidence Score)
- ภาพ snapshot

### 5.3 รายงานสรุปประจำเดือน (Monthly Report)

เมนู **Attendance → Monthly Report**
- เลือกเดือนที่ต้องการ
- เลือกแผนก (หรือทั้งหมด)
- ดูกราฟและตารางสรุป

## 6. รายงาน PDF

ส่งออกรายงานเป็นไฟล์ PDF ที่พิมพ์ได้ รองรับ**ภาษาไทย**

### 6.1 PDF รายวัน

1. ไปที่ **Attendance → Daily Status**
2. เลือกวันที่และแผนก
3. กดปุ่ม **"Export PDF"**
4. ไฟล์ดาวน์โหลดอัตโนมัติ: `attendance_daily_YYYY-MM-DD.pdf`

**เนื้อหาใน PDF:**
- หัวรายงาน + วันที่
- ตารางพนักงาน: รหัส / ชื่อ / แผนก / เวลาเข้า / สถานะ (สีรหัส)
- สรุปจำนวน PRESENT / LATE / ABSENT

### 6.2 PDF รายเดือน

1. ไปที่ **Attendance → Monthly Report**
2. เลือกเดือน
3. กดปุ่ม **"Export PDF"**
4. ไฟล์ดาวน์โหลด: `attendance_monthly_YYYY-MM.pdf`

**เนื้อหาใน PDF:**
- สรุปสถิติเดือน (Total / Unique Employees)
- ตารางรายวัน (ทุกวันในเดือน)
- ตารางแยกตามแผนก

### 6.3 Export CSV

กดปุ่ม **"Export CSV"** (อยู่ข้าง Export PDF) — ได้ไฟล์ `.csv` สำหรับนำไปใช้ใน Excel

## 7. ตั้งค่ากล้อง (Station)

เมนู **Stations** (ต้องการสิทธิ์ ADMIN)

### 7.1 Station คืออะไร

Station = จุดแสกน 1 จุด เช่น "ประตูหน้า", "ทางเข้าโรงงาน"
แต่ละ Station สามารถมีกล้องได้หลายตัว

### 7.2 เพิ่ม Station ใหม่

1. กด **"+ Add Station"**
2. ตั้งชื่อ เช่น `ประตูหน้า`
3. เลือกแผนกที่รับผิดชอบ (Dept Filter) — ถ้าเลือก "ทั้งหมด" จะจำใบหน้าทุกคน
4. กด **"Save"**

### 7.3 เชื่อมต่อกล้อง

| ประเภทกล้อง | วิธีเชื่อมต่อ |
|------------|------------|
| **Webcam** (USB/built-in) | เปิดหน้า Scan → ใช้ได้เลย |
| **Smartphone** | เปิด `/mobile-scan` บน browser มือถือ |
| **IP Camera / CCTV** | ใช้ RTSP Bridge — ดู [คู่มือ Deployment](DEPLOYMENT.md#rtsp-camera) |

### 7.4 หน้า Mobile Scan

เหมาะสำหรับใช้มือถือเป็นกล้องสแกน:
1. เปิด browser บนมือถือ → ไปที่ `http://[IP ของ server]:5173/mobile-scan`
2. Login → ระบบเริ่มสแกนอัตโนมัติ
3. เมื่อจำใบหน้าได้ → แสดงชื่อพนักงานพร้อมเสียงยืนยัน

## 8. ตั้งค่าระบบ

เมนู **Settings** (ต้องการสิทธิ์ ADMIN)

### 8.1 การตั้งค่าสำคัญ

#### ⏰ เวลาทำงาน

| Setting | ค่าเริ่มต้น | ความหมาย |
|---------|-----------|---------|
| `work_start_time` | `08:00` | เวลาเริ่มงาน |
| `late_threshold_minutes` | `15` | สายได้กี่นาที (15 = ถ้าเข้าหลัง 08:15 คือสาย) |

#### 🎯 ความแม่นยำ Face Recognition

| Setting | ค่าเริ่มต้น | ความหมาย |
|---------|-----------|---------|
| `match_threshold` | `0.72` | ความเชื่อมั่นขั้นต่ำ (0.0–1.0) — สูงขึ้น = เข้มงวดขึ้น |
| `min_face_quality` | `0.5` | คุณภาพภาพใบหน้าขั้นต่ำ |

> **แนะนำ:** อย่าเปลี่ยน `match_threshold` ถ้าไม่มีปัญหา — ค่า 0.72 ผ่านการทดสอบแล้ว

#### ⚡ Performance

| Setting | ค่าเริ่มต้น | ความหมาย |
|---------|-----------|---------|
| `inference_workers` | `4` | จำนวน thread ประมวลผล AI (เพิ่มถ้า CPU แรงพอ) |
| `max_fps_per_camera` | `2` | FPS ต่อกล้อง — ลดถ้า CPU สูงเกิน |
| `recognition_cache_ttl` | `30` | วินาทีที่ cache ผลจำใบหน้า (ลดการ query ซ้ำ) |

#### 🔔 Notifications

| Setting | ความหมาย |
|---------|---------|
| `webhook_url` | URL สำหรับส่งแจ้งเตือน (Discord/Slack/Telegram/Line) |
| `notification_on_recognize` | แจ้งทุกครั้งที่จำได้ |
| `notification_on_absent` | แจ้งเมื่อพนักงานไม่มาตามเวลา |

#### 🛡️ Security

| Setting | ค่าเริ่มต้น | ความหมาย |
|---------|-----------|---------|
| `access_token_expire_hours` | `8` | Token หมดอายุกี่ชั่วโมง |
| `anti_spoof_enabled` | `0` | เปิด liveness detection (1=เปิด, ต้องมีโมเดล) |

### 8.2 จัดการผู้ใช้

เมนู **Settings → Users**

| การกระทำ | สิทธิ์ที่ต้องการ |
|---------|--------------|
| เพิ่มผู้ใช้ | ADMIN |
| เปลี่ยน password | ADMIN หรือเจ้าของ account |
| เปลี่ยน role | ADMIN |
| ปิดการใช้งาน user | ADMIN |

## 9. บทบาทผู้ใช้ (Roles)

| บทบาท | สิ่งที่ทำได้ |
|-------|-----------|

## 10. คำถามที่พบบ่อย

### ❓ ระบบจำใบหน้าไม่ได้

**สาเหตุ:**
- ยังไม่ได้ Enroll (ดูส่วนที่ 4)
- แสงน้อยเกินไป
- ใส่หน้ากากหรือแว่นตาทึบ
- ยืนไกลกล้องเกิน 2 เมตร

**แก้ไข:**
- ตรวจสอบว่า Enrollment count = 6/6 ✅
- ปรับแสงให้เพียงพอ
- ยืนใกล้กล้องมากขึ้น

---

### ❓ พนักงานแสกนแล้ว แต่สถานะยังเป็น ABSENT

**สาเหตุ:**
- Confidence Score ต่ำกว่า threshold → ระบบไม่บันทึก
- แสกนหลังเวลาที่ระบบ mark absent ไปแล้ว

**แก้ไข:**
- ดู Attendance Log → ตรวจสอบว่ามี record หรือไม่
- ถ้าไม่มี → ต้องแก้ไขด้วย HR manually หรือปรับ threshold

---

### ❓ กล้องไม่แสดงภาพ

**แก้ไข:**
1. รีเฟรชหน้า browser
2. ตรวจสอบว่า browser ได้รับอนุญาตใช้กล้อง (ไอคอนกล้องใน address bar)
3. ลอง browser อื่น (Chrome แนะนำ)
4. ตรวจสอบ backend log ที่ terminal

---

### ❓ ต้องการ Export ข้อมูลทั้งหมดออกมา

ใช้ API โดยตรง:
```
GET /api/v1/attendance?limit=10000
Authorization: Bearer <token>
```

หรือ export CSV จากหน้า Attendance

---

### ❓ Notification ไม่ส่ง

ตรวจสอบ:
1. **Settings → Notifications** → ใส่ `webhook_url` ถูกต้องหรือยัง
2. ทดสอบ webhook URL ที่ Discord/Telegram/Slack ก่อน
3. ดู backend log สำหรับ error

---

### ❓ Login ไม่ได้ / ลืม Password

ให้ ADMIN reset password ที่ **Settings → Users → [ชื่อ user] → Change Password**

ถ้า ADMIN ลืม password เอง ต้องแก้ผ่าน database:
```bash
docker exec -it omnisight_postgres psql -U omnisight -c \
  "UPDATE users SET hashed_password='...' WHERE username='admin';"
```
(ติดต่อ IT เพื่อรีเซ็ต)
